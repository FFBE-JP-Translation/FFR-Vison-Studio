# Effect review surface

Mode: Operate, with a Read section for FFR mechanics. Inherits FFR's strategy
guide visual system: paper, ink rules, Barlow, compact tables and native form
controls. The user's task explicitly requires an editable parity table, so its
structure is a searchable table and a selected-effect detail pane, with a
separate FFR guide and source/next-step documentation.

Success: review hundreds of shared effects once, save decisions durably, and
carry them into the exhaustive ability conversion after user review. Default
proposals, user intent, source evidence and runtime validation are distinct.

No hosted deployment, account or external fonts. The page is an artifact and a
local editing tool within the existing repository, not a replacement for Studio.
