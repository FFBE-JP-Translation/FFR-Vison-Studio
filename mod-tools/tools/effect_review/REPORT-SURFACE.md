# Ability report surface

Mode: Operate, with Read content for source evidence and rule outcomes.
Inherits the existing effect-review strategy-guide system: Barlow, white paper,
ink rules, compact native controls, and clear good/bad/partial text badges.

The list reads a paginated SQLite report, never a sample or client-side subset.
The detail compares original descriptions, output, omitted components, applied
notes and native drafts. Search, source/kind/effect filters, source-key links,
page navigation and save conflicts retain full provenance. A separate effect
table exposes all 346 shared rules and their exhaustive occurrence counts.

Review marks are optional annotations. Overall approval can be given in
conversation; the UI must never impose a 658,544-click approval requirement.
Saving a review cannot create abilities, write a final unit list, or install.

Visual QA: desktop at the actual 951px browser width and mobile at 390px;
both have no document-level horizontal overflow. Native tables scroll inside
their own region on mobile. The detail moves below the result list there.
