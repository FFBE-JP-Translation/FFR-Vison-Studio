A Windows app that puts Final Fantasy Brave Exvius units into the FINAL FANTASY RESONANCE demo. Pick a unit. Drag the game's own abilities and passives onto its awakening tiers. Set the stats. Its Resonance uses its own FFBE limit-burst motion, charging sound and attack sounds, with an elemental field color you can customize. Press GO and the unit is in the Mitra item shop the next time you start the game.

Build 15 restores unit imports and Brave Shift choices in Advanced Studio. Create your own units with a PNG sprite sheet, animation JSON and an editable profile, with downloadable templates to get started. Browsing uses cached idle previews; adding a hosted unit downloads its complete data with progress shown before the editor opens. Incomplete resonances remain labelled while their mechanics, sounds and effects are being expanded.

The first start downloads the engine and data packs, then reads your copy of the game once. Nothing in the game folder changes until you press "Install into the game", and one button puts the game back the way Steam installed it.

Download FFR Vision Studio

A zip. Unpack it anywhere and start FFR Vision Studio.exe. No installer, no scripts.

Before you start
  1. The FINAL FANTASY RESONANCE demo installed through Steam. The app finds it on its own; if it is somewhere unusual, browse to the folder that holds FFRS.exe.
  2. Keep the game closed while installing. The mod is three files in FFRS/Content/Paks/~mods; the app backs up whatever it replaces and "Restore the original game" removes them again.
  3. Windows may warn about an unsigned download. Choose "More info" and "Run anyway"; the app and its engine are open source.
